# Personal Expense Tracker - Project Overview

## 1. Introduction
The Personal Expense Tracker is a full-stack web application designed to help people track their daily income and expenses. The goal is to provide an easy way for users to see where their money is going and manage their savings effectively. The project is live and deployed on cloud infrastructure.

## 2. Why this project?
Many people struggle to remember their daily small expenditures like snacks, transport, or small bills. Manual tracking on paper is difficult and often ignored. This app provides a digital way to log and visualize these expenses instantly.

## 3. Main Goals
*   Create a private account for each user to store their data securely.
*   Allow users to easily add, update, or delete transactions.
*   Display a clear "Total Balance" summary with income/expense breakdown.
*   Show a visual Pie Chart to analyze spending by category (e.g., Food, Travel, Rent).

## 4. Technology Stack
*   **Frontend:** React 18 + Vite (fast and responsive user interface with Recharts visualization).
*   **Backend:** FastAPI + Gunicorn (high-performance Python API server).
*   **Database:** MongoDB Atlas (NoSQL cloud database for scalable document storage).
*   **Hosting:** Netlify (Frontend) + Render (Backend).

## 5. Project Features (Scope)
| **Feature** | **Description** |
| :--- | :--- |
| **User Auth** | Secure registration and login with bcrypt password hashing. |
| **Add/Edit/Delete Transaction** | Full CRUD for income and expense entries. |
| **Dashboard** | Summary page showing balance, total income, and total expense. |
| **Spending Pie Chart** | Visual Recharts pie chart grouped by category. |
| **Transaction History** | Complete list of all past entries with edit/delete controls. |
| **Budget Tracking** | Visual budget progress bar per category. |
